# Aster Agent 单次任务流程

状态：本流程已迁移为可自动加载的 Skill：`.agents/skills/aster-workflow/SKILL.md`（ZCode 与 Codex 的官方项目级 Skill 路径均为仓库内 `.agents/skills/`）。本文件保留为不依赖特定工具加载机制的参考文档；内容以 Skill 为准。

## 执行一次标准任务

1. **检查**：完整阅读 `AGENTS.md`、`PLAN.md`、相关需求/ADR 和 `DEVLOG.md` 最近记录；查看 Git 状态与相关代码。
2. **计划**：复述当前里程碑的目标、范围、非目标、预计文件、验收标准、风险和假设。若任务越过人工确认门，停止。
3. **实现**：只做当前验收所需的最小改动；保留已有修改，不预建未来框架。
4. **验证**：执行能证明关键行为的最少测试/检查；记录实际命令和无法验证项。
5. **自审**：查看完整状态和 diff，检查无关修改、秘密、平台 SDK 泄漏到 Core、无依据抽象和文档状态措辞。
6. **记录**：更新 `PLAN.md` 和 `DEVLOG.md`；重大且已由人工接受的决定才写 ADR。
7. **停止**：按验收标准汇报已完成、已验证、未验证和待决定内容，不自动进入下一里程碑。

若仓库状态、用户已有改动或高成本选择不清楚，先完成所有安全的只读检查，再请求人工决定。
